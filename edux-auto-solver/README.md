# EDUX ULTIMATE LIFEFORM v3.0 - CMCU LMS (AI CODING CLI & CMCU-VẠN-NĂNG V3.2 FIX)

Hệ thống tự động hóa thông minh hỗ trợ giải bài tập trắc nghiệm, đúng/sai (4 mệnh đề con), tự luận và **chạy slide học liệu (100% Trợ giảng)** trên hệ thống EduX CMCU (`https://edux.cmcu.edu.vn`).

- **Không cần Gemini API Key**: Kết nối trực tiếp vào **Google Antigravity CLI (`agy`)**, **OpenAI Codex CLI (`codex`)**, **Claude Code CLI (`claude`)** và **OpenCode (`opencode`)**.
- **Slide Engine**: Sử dụng **CMCU-Vạn-Năng-V3.2 FIX** (sửa lỗi tự qua câu & xác nhận 3/3 nhịp ở trang cuối chống dừng sớm).
- **Khởi chạy trên Linux**: Chạy `./run.sh` hoặc `./run.sh --cli`.
